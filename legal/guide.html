Member guide

How to get in, use the models and use the API

Aaru runs open-weight AI models on a private server. Your use is covered by the Terms, the Acceptable Use Policy and the Privacy Notice; the short version is that models run locally, nothing is used for training, and chats are stored on the server (not end-to-end encrypted) until you delete them.

1. Getting in

Aaru is reached over a private network (Tailscale) while its public address is being set up.

  1. Accept the share invitation you received from the operator. Install Tailscale on each device you will use and sign in with any account of your own. You will see one shared machine, aaru; nothing else on the operator's network is visible to you.
  2. With Tailscale connected, open {{SERVICE_URL}} and sign in with the email address and temporary password the operator gave you. There is no public sign-up.
  3. Change your password (Settings → Account).

2. Installing it as an app

  • iPhone or iPad: open the address in Safari, tap Share, then Add to Home Screen.
  • Android: open it in Chrome, open the menu, then Install app.
  • Desktop: in Chrome or Edge, use the install icon in the address bar.

Tailscale has to be connected for the app to reach Aaru.

3. Choosing a model

ModelGood for
fastEveryday chat, drafting, quick answers, images in your messages. The default.
denseLonger or more careful work where steadiness matters more than speed. Also reads images.
reasoningMulti-step problems, analysis, code. Slower, and thinks before it answers.

Models load when first asked for. If a model has been idle, the first reply can take a minute or two while it loads; replies after that are quick. Only one of the larger models is loaded at a time, so switching between them also means a short wait.

Documents: attach a file to a chat, or add files to a knowledge collection in the Workspace to ask questions across them. Answers cite the passages they used.

Temporary chats are not saved to your history.

AI output can be wrong. Check anything important, and do not rely on it for medical, legal, financial or safety decisions.

4. Using the API

Aaru speaks the OpenAI API, so most tools work by changing the base URL. Ask the operator for an API key; it is shown to you once, so store it somewhere safe and never share it.

Base URL: {{SERVICE_URL}}:8443/v1
Models: fast, dense, reasoning, and embed / embed-small for embeddings

curl {{SERVICE_URL}}:8443/v1/chat/completions \
  -H "Authorization: Bearer $AARU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "fast", "messages": [{"role": "user", "content": "Hello"}]}'
import os
from openai import OpenAI
client = OpenAI(base_url="{{SERVICE_URL}}:8443/v1", api_key=os.environ["AARU_API_KEY"])
reply = client.chat.completions.create(model="fast", messages=[{"role": "user", "content": "Hello"}])

Editor assistants that accept an OpenAI-compatible provider (for example Continue) work the same way: set the base URL, the key and a model name.

Limits: each key has per-minute request and token limits and a cap on parallel requests (by default 30 requests and 100,000 tokens a minute, 2 at once). Going over returns HTTP 429; wait and retry. Ask the operator if your use needs more.

5. Your data
