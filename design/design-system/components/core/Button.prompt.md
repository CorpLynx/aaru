Aaru action button; use for any clickable command. One `primary` per view.

```jsx
<Button variant="primary" icon="plus">New chat</Button>
<Button variant="danger">Delete vault</Button>
<Button size="sm" variant="ghost">Copy</Button>
```

- `size`: sm (IDE 28px), md (web 36px), lg (mobile 44px).
- Primary is off-white (#EDEFF2) on ink text. Never use Ember/Cipher as a button fill.
