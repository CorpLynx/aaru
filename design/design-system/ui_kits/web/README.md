# Web app — chat.aaru.ai
Click-through: Unlock (lock icon in rail) → chat thread → send a message (fake stream with Ember pulse) → Quick/Deep toggle inserts a divider → Vault panel: click "Drop files" to watch the sealing sequence, click rows to toggle context → avatar row opens Billing (plan, next payment, card, invoices, cancel dialog) → Change plan opens Membership plans.
Files: UnlockScreen, Sidebar, Thread, VaultPanel, PlansScreen, stream.js (shared fake streamer). Built only from components/.
