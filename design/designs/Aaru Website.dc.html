What does "unmetered" mean?
There are no per-token charges. When the hardware is busy, requests queue by tier priority instead of being billed or cut off.
Why does the Founders rate drop?
The first twelve months pay for the hardware. After that, Founders cover only their share of power and upkeep: $15/mo.
Can I switch plans?
Yes, at any time. Your encrypted history and vault stay with your account on every tier.

What the admin can see
Your email address and membership tier, for billing Request counts, timing and token totals, for queue fairness Storage used by your encrypted vault GPU load and system health
The honest limit
To generate a reply, the model has to read your prompt in plaintext, in GPU memory, for the few seconds the request runs. It is never written to disk unencrypted, and it never leaves the hardware. Lose your passphrase and your history can't be recovered, by you or by us.

DOCS · QUICKSTART

Make your first request

Aaru exposes an OpenAI-compatible API. API keys are included with the Chat tier and above.

1. Create an API key

In the web app, open Settings → API keys and select New key. Keys start with aaru_sk_ and are shown once.

2. Call the endpoint

curlCopy
curl https://api.aaru.ai/v1/chat/completions \ -H "Authorization: Bearer $AARU_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model": "nemotron-3.5", "messages": [{"role": "user", "content": "Hello"}]}'

3. Pick a model

MODEL IDTYPEFROM TIER
nemotron-3.5Quick · sparse MoECasual
llama-70bDeep · heavy denseDev

4. Connect your editor

In Continue.dev, add a model with provider openai, set apiBase to the Aaru URL, and paste your key. Any tool that lets you override the OpenAI base URL works the same way.

Model IDs and the base URL are placeholders until the API is live.
